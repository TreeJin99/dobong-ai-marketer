# 처음 쓰는 코덱스 · 나를 소개하는 사이트 만들기

도봉여성새로일하기센터 「AI 기반 디지털 마케터 양성과정」 실습 폴더입니다.
코딩을 몰라도 코덱스(Codex)에게 말로 시켜서 나를 소개하는 사이트를 만들고, 인터넷에 올리고, 글과 카드뉴스를 더해 갑니다.

## 1. 받기

1. 이 페이지 위쪽 초록색 「Code」 버튼 → 「Download ZIP」
2. 받은 파일의 압축을 풉니다
3. 풀린 폴더 안의 것을 **전부** 바탕화면 「내프로젝트」 폴더에 넣습니다
   - AGENTS.md 는 덮어씁니다
   - 9/14 에 만든 보고서(01_개요 ~ 04_보고서)와 작업파일 폴더는 그대로 둡니다
   - 「내프로젝트」 폴더가 없으면 풀린 폴더 이름을 「내프로젝트」로 바꿔 바탕화면에 둡니다

맥에서는 점(.)으로 시작하는 `.agents` 폴더가 숨겨져 보이지 않을 수 있습니다. 그래도 들어 있으니 그대로 옮기면 됩니다. 보려면 Finder 에서 `Command + Shift + .`

## 2. 열기

1. ChatGPT 앱을 열고 왼쪽 위에서 「Codex」
2. 「폴더 열기」 → 바탕화면 → 「내프로젝트」
3. 아래 한 줄을 보냅니다

```
$start 로 처음부터 도와주세요
```

코덱스가 세 가지(주제 · 별명 · 좋아하는 색)를 하나씩 묻고, 사이트를 만들고, 다음에 보낼 한 문장을 알려 줍니다.
파일을 만들기 전에 허락 창이 뜨면 「허용」을 누르세요.

## 3. 폴더 안에 무엇이 있나

```
내프로젝트/
  AGENTS.md            규칙서. 코덱스가 이 폴더에서 항상 먼저 읽는 설명서
  사이트재료_예시.md     9/14 보고서가 없을 때 쓰는 예시 재료
  .agents/skills/      기술(부를 때만 읽는 설명서) 여덟 개
    start/             처음 시작 · 사이트 만들기 길잡이
    baseline/          기준점 · 검색에 내 이름이 나오는지 기록
    cardnews/          카드뉴스 5장 만들기
    blog/              블로그 글 1편 쓰기
    shorts/            15초 세로 영상 만들기
    storyboard/        영상 스토리보드 5장면 기획
    motion/            20초 모션그래픽 영상 만들기
    report/            주간 리포트 1장
  9월/                 9월 수업 자료 (사주 · 자기소개 프롬프트)
```

기술은 이름 앞에 `$` 를 붙여 부릅니다. 예: `$cardnews 로 카드뉴스 만들어 주세요`

## 4. 지켜 주세요

- 사이트에는 실명 · 전화번호 · 주소를 넣지 않습니다. 이름은 별명으로 씁니다.
- 코덱스는 가끔 틀리게 말합니다. 숫자와 출처는 직접 열어 확인합니다.
- 남의 사진 · 로고는 넣지 않습니다.

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 기술이 안 보여요 | 「폴더 열기」로 「내프로젝트」를 다시 고르기 |
| 아무 반응이 없어요 | 화면 아래 허락 창이 떠 있는지 보고 「허용」 |
| 「한도」라고 나와요 | 잠시 기다렸다가 같은 문장을 다시 보내기 |
| 사이트가 안 열려요 | 내프로젝트 → 내사이트 → index.html 더블클릭 |
