# 처음 쓰는 코덱스 · 내 서비스 웹앱 만들기

도봉여성새로일하기센터 「AI 기반 디지털 마케터 양성과정」 실습 폴더입니다.
코딩을 몰라도 코덱스(Codex)에게 말로 시켜서 Next.js(웹사이트 뼈대 도구)로 내가 만들고 싶은 서비스 웹앱과 그 서비스를 소개하는 랜딩페이지를 만들고, 인터넷에 올리고, 한 문장으로 운영하고, 카드뉴스와 글을 더해 갑니다.

예: 붕어빵 파는 곳 지도 · 동네 가게 목록 · 회비 나누기 계산기 · 나에게 맞는 ○○ 테스트 · 할 일 기록장

**백엔드(서버) 없는 서비스만 만듭니다.** 로그인 · 회원가입 · 결제 · 손님이 글을 올리는 게시판 · 예약 받기는 넣지 않고, 정보는 내가 한 문장으로 직접 넣습니다.

준비물: 컴퓨터에 Node.js(무료, https://nodejs.org 의 LTS)가 깔려 있어야 합니다. 처음 한 번 꾸러미를 받는 데 1~3분, 저장 공간 약 350MB 가 듭니다.

## 1. 받기

1. 이 페이지 위쪽 초록색 「Code」 버튼 → 「Download ZIP」
2. 받은 파일의 압축을 풉니다
3. 풀린 폴더 안의 것을 **전부** 바탕화면 「내프로젝트」 폴더에 넣습니다
   - AGENTS.md 는 덮어씁니다
   - 9/14 에 만든 보고서(01_개요 ~ 04_보고서)와 작업파일 폴더는 그대로 둡니다
   - 「내프로젝트」 폴더가 없으면 풀린 폴더 이름을 「내프로젝트」로 바꿔 바탕화면에 둡니다

맥에서는 점(.)으로 시작하는 `.agents` 폴더가 숨겨져 보이지 않을 수 있습니다. 그래도 들어 있으니 그대로 옮기면 됩니다. 보려면 Finder 에서 `Command + Shift + .`

## 2. 열기

1. ChatGPT 앱을 열고 왼쪽 위에서 「Codex」
2. 「폴더 열기」 → 바탕화면 → 「내프로젝트」
3. 아래 한 줄을 보냅니다

```
$start 로 처음부터 도와주세요
```

코덱스가 네 가지(누구의 어떤 불편 · 비슷한 앱 유형 · 서비스 이름과 별명 · 좋아하는 색)를 하나씩 묻고, 기획 한 장을 보여 준 뒤 「좋아요」를 받으면 웹앱과 소개 페이지를 만들고, 다음에 보낼 한 문장을 알려 줍니다.
파일을 만들기 전에 허락 창이 뜨면 「허용」을 누르세요.

## 3. 폴더 안에 무엇이 있나

```
내프로젝트/
  AGENTS.md            규칙서. 코덱스가 이 폴더에서 항상 먼저 읽는 설명서
  사이트재료_예시.md     9/14 보고서가 없을 때 쓰는 예시 재료
  내사이트/            내 서비스 웹사이트 (Next.js 뼈대)
  .agents/skills/      기술(부를 때만 읽는 설명서) 아홉 개
    start/             처음 시작 · 서비스 기획 → 내사이트 채우기 (웹앱 + 소개 페이지)
    update/            운영하기 · 한 문장으로 장소 추가 · 공지 바꾸기 · 다시 올리기
    baseline/          기준점 · 검색에 내 이름이 나오는지 기록
    cardnews/          카드뉴스 5장 만들기
    blog/              블로그 글 1편 쓰기
    shorts/            15초 세로 영상 만들기
    storyboard/        영상 스토리보드 5장면 기획
    motion/            20초 모션그래픽 영상 만들기
    report/            주간 리포트 1장
  9월/                 9월 수업 자료 (사주 · 자기소개 프롬프트)
```

기술은 이름 앞에 `$` 를 붙여 부릅니다. 예: `$cardnews 로 카드뉴스 만들어 주세요`

「내사이트」 폴더에는 Next.js 뼈대가 미리 들어 있습니다. 코덱스는 아래 세 곳만 채웁니다.

```
내프로젝트/내사이트/
  data/site.js        서비스 이름 · 한 줄 약속 · 소개 페이지 글
  data/app-data.js    장소 · 항목 · 공지 한 줄. 운영할 때는 여기만 바뀜
  app/globals.css     글꼴 · 색 · 크기. 맨 위 --brand 한 줄이 내 색
  app/page.jsx        서비스 화면 (주소 /)
  app/about/page.jsx  서비스 소개 랜딩페이지 (주소 /about, 나중에 광고 도착 페이지)
  components/         지도 · 목록 · 계산기 · 테스트 · 기록 화면 다섯 가지
  next.config.mjs     서버 없이 올리는 설정 (지우지 않음)
```

만든 화면은 코덱스가 띄워 줍니다. 내 컴퓨터 주소는 http://localhost:3000 (소개는 /about) 입니다.

## 운영하는 법

웹앱을 만든 뒤에는 아래 문장을 복사해 「…」 부분만 바꿔 보내면 됩니다. 바꾼 내용은 `data/app-data.js` 에 들어가고 `작업파일/운영기록.md` 에 한 줄씩 남습니다.

```
장소 추가해 주세요: 쌍문역 3번 출구 앞
```

```
예시 1번 가게를 지워 주세요
```

```
공지 한 줄 바꿔 주세요: 겨울 동안 매주 금요일에 새 장소를 더합니다
```

```
예시를 다 지워 주세요
```

```
다시 올려 주세요
```

마지막 「다시 올려 주세요」를 보내야 인터넷 주소에도 바뀐 내용이 보입니다.

## 4. 지켜 주세요

- 웹앱에는 실명 · 전화번호 · 주소를 넣지 않습니다. 이름은 별명으로 씁니다.
- 실제 가게 이름 · 후기 · 숫자를 지어내지 않습니다. 예시는 화면에 「예시」라고 보입니다.
- 코덱스는 가끔 틀리게 말합니다. 숫자와 출처는 직접 열어 확인합니다.
- 남의 사진 · 로고는 넣지 않습니다.

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 기술이 안 보여요 | 「폴더 열기」로 「내프로젝트」를 다시 고르기 |
| 아무 반응이 없어요 | 화면 아래 허락 창이 떠 있는지 보고 「허용」 |
| 「한도」라고 나와요 | 잠시 기다렸다가 같은 문장을 다시 보내기 |
| 화면이 안 열려요 | 「화면 다시 띄워 주세요」를 보내고 http://localhost:3000 열기 |
| Node.js 가 없대요 | 강사에게 Node.js 설치를 부탁하기 |
| 지도가 회색이에요 | 인터넷 연결을 확인하고, Vercel 에 올린 주소에서 다시 보기 |
