# AI 기반 디지털 마케터 양성과정 · 실습 폴더

도봉여성새로일하기센터 · 지금.lab 남우진

코덱스(Codex CLI)로 바로 쓸 수 있게 만든 실습 폴더입니다.
이 폴더를 열면 코덱스가 `AGENTS.md` 를 읽고 규칙대로 답합니다.

## 받는 법

1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP**
2. 받은 파일의 압축을 풀어 **바탕화면**에 둡니다
3. 폴더 이름을 `내작업` 으로 바꿉니다

## 여는 법

1. VS Code 실행
2. 위쪽 메뉴 **File → Open Folder** → 방금 만든 `내작업` 폴더 선택
3. 아래쪽 터미널 칸을 클릭하고 `codex` 입력 후 Enter
4. "이 폴더를 믿습니까" → **1번 Yes**

설치가 아직이면 [명령어.md](명령어.md) 를 먼저 보세요.

## 폴더 안에 무엇이 있나

```
내작업/
  AGENTS.md      나에 대한 규칙서. 본인 것으로 고쳐서 씁니다
  명령어.md       복사해서 쓰는 설치 명령어
  prompts/       자주 쓰는 프롬프트 모음
    사주.md
    자기소개.md
    mbti.md
```

## 써보기

코덱스를 켜고 한국어로 그냥 말하면 됩니다.

```
나를 소개하는 글 3줄을 규칙서 말투로 써서 소개.md 로 저장해줘
```

```
사주.md 에 적힌 대로 1990년 3월 5일생 사주를 봐주고
결과를 내사주.md 파일로 저장해줘
```

## 막히면

| 상황 | 이렇게 말하세요 |
| --- | --- |
| 마음에 안 들 때 | 다시 써줘. 더 짧게. |
| 말투가 이상할 때 | 더 부드럽게 바꿔줘. |
| 파일이 안 보일 때 | 방금 만든 파일 어디 있어? |
| 아예 모르겠을 때 | 뭘 할 수 있는지 알려줘. |
