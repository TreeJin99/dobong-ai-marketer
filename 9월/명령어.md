# 복사해서 쓰는 명령어

터미널이나 VS Code 아래 칸에 그대로 붙여넣으세요.

## 1. 설치 확인

```
node -v
```

숫자가 나오면 성공입니다. (예: v20.11.0)

## 2. 코덱스 설치

```
npm install -g @openai/codex
```

1~2분 걸립니다. 글자가 멈추면 끝난 것입니다.

## 3. 코덱스 실행

```
codex
```

브라우저가 열리면 쓰시던 ChatGPT 계정으로 로그인합니다.
"이 폴더를 믿습니까" 를 물으면 **1번 Yes** 를 고릅니다.

## 안 될 때

| 증상 | 해결 |
| --- | --- |
| 숫자가 안 나옴 | 터미널을 껐다 켜기 → 그래도 안 되면 Node.js 재설치 |
| 권한 오류 | 터미널을 관리자 권한으로 다시 열기 |
| 로그인이 안 됨 | 브라우저에서 ChatGPT에 먼저 로그인한 뒤 다시 시도 |
