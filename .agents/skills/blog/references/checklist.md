# 되는 글 다섯 (점검표)

글 맨 끝 「점검」 칸에 아래 모양 그대로 적습니다.

| 점검 | O · X | 근거 (글에서 해당 부분을 짧게 옮김) |
|---|---|---|
| 1. 제목에 주제어 | | 제목에 들어간 검색어 |
| 2. 첫 세 문장에 결론 | | 첫 문장 |
| 3. 직접 겪은 것 | | 그 단락의 첫 문장 |
| 4. 숫자와 날짜 | | 숫자 · 기관 · 연도 |
| 5. 한 글에 한 가지 | | 이 글의 한 가지를 한 줄로 |

판정 기준:
- 1번: 제목 안에 검색어가 띄어쓰기까지 그대로 있으면 O
- 2번: 앞 세 문장만 읽어도 질문의 답이 나오면 O. 인사말로 시작하면 X
- 3번: AGENTS.md 나 사이트재료.md, 사용자가 말해 준 경험이 들어 있으면 O. 지어낸 경험이면 X
- 4번: 숫자에 기관과 연도가 붙어 있으면 O
- 5번: 소제목 3개가 모두 같은 질문에 답하면 O
