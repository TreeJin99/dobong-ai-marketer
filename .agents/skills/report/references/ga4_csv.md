# GA4 에서 내보낸 CSV 읽는 법

## 파일 모양
- `#` 으로 시작하는 줄은 설명입니다. 여기에 시작일 · 종료일이 들어 있는 경우가 많습니다 (예: `# 시작 날짜: 20261014`, `# Start date: 20261014`).
- 빈 줄로 표가 나뉩니다. 한 파일에 표가 여러 개 있을 수 있습니다.
- 각 표의 첫 줄이 열 이름입니다. 화면 언어에 따라 한국어 또는 영어입니다.

## 찾을 열 이름
| 리포트에 쓸 이름 | 한국어 열 이름 | 영어 열 이름 |
|---|---|---|
| 사용자 | 사용자, 활성 사용자, 총 사용자 | Users, Active users, Total users |
| 세션 | 세션 | Sessions |
| 참여 세션 | 참여 세션수, 참여 세션 | Engaged sessions |
| 유입 소스 | 세션 소스/매체, 세션 기본 채널 그룹 | Session source / medium, Session default channel group |
| 이벤트 | 이벤트 수, 이벤트 이름 | Event count, Event name |

## 규칙
- 열 이름이 위와 다르면 비슷한 열을 골라 쓰지 말고, 찾은 열 이름 목록을 보여 주며 어느 것인지 묻습니다.
- 표 맨 아래 「합계」「Total」 줄이 있으면 그 줄을 이번 주 숫자로 씁니다. 날짜별 줄을 직접 더하지 않습니다 (사용자 수는 더하면 틀립니다).
- 유입 소스는 세션이 많은 순서로 3개만 옮깁니다.
- 숫자의 쉼표(1,234)는 그대로 둡니다. 소수점은 반올림하지 않고 GA4 에 나온 대로 옮깁니다.
- 리포트의 「숫자 출처」 칸에 CSV 파일 이름을 적습니다.
