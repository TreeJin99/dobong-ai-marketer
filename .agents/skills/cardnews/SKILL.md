# 카드뉴스 5장 (cardnews)

내 사이트 재료를 인스타그램 카드 5장으로 바꾸는 일입니다. 글자는 정해진 틀(1080×1350)에 넣어 사진처럼 찍습니다. 그림을 만드는 AI는 글자를 틀리게 쓰기 때문에, 글자가 들어가는 일에는 쓰지 않습니다.

## 준비
1. AGENTS.md 「나와 내 주제」「브랜드 규칙」을 읽습니다. 재료는 이 순서로 고릅니다.
   - 사용자가 글 1편을 말하면 그 글.
   - `내사이트/posts/` 에 글이 있으면 기존대로 사이트재료.md 와 그 글.
   - 글이 아직 없으면 `내사이트/data/site.js` 의 about(서비스 소개 랜딩페이지 글)과 `작업파일/서비스기획.md`. 이때 2장 「문제」는 「이런 불편 있으셨죠」, 4장 「해결」은 「이렇게 해결」의 기능 3개, 5장 「행동」은 「지금 써 보기」로 앱에 오게 하고, brand 는 「한 줄 약속」을 씁니다. 랜딩페이지에 없는 후기 · 숫자는 만들지 않습니다.
2. 「내 사이트 주소」가 비어 있거나 괄호 안내문 그대로면 사용자에게 묻습니다. 답이 없으면 `(내 사이트 주소)` 로 두고 끝날 때 알려 줍니다.
3. 「좋아하는 색」을 색 코드(#으로 시작하는 6자리)로 정합니다. 색 이름만 있으면 흰 글자가 잘 읽히는 진한 색으로 하나 고르고, 고른 코드를 알려 줍니다.
4. 대괄호 `[ ... 넣으세요]` 로 된 칸은 아직 안 채운 칸입니다. 내용으로 쓰지 않습니다.

## 다섯 장의 글 정하기
| 장 | 역할 | 쓰는 법 |
|---|---|---|
| 1 표지 | 주제 한 줄 | 손님 입장의 한 줄. 20자 안팎, 두 줄까지 |
| 2 문제 | 손님의 불만 1개 | 재료나 보고서에 있는 불만만. 실제 후기 문장이 있으면 그대로 옮기고, 없으면 따옴표 문장을 비웁니다 |
| 3 근거 | 숫자 1개와 기관 | 숫자 · 단위 · 뜻 한 줄 · 「기관, 연도」 |
| 4 해결 | 내가 할 수 있는 것 | 사이트재료.md 「내가 할 수 있는 것」에서 3개. 하나에 16자 안팎 |
| 5 행동 | 사이트로 오게 하기 | 한 줄 안내 + 사이트 주소(https:// 뺀 것) + 「자세히 보기」 |

근거 숫자를 찾는 순서:
1. 사이트재료.md · 서비스기획.md · data/site.js → 작업파일 폴더의 원본 글(01_개요.md · 04_보고서.md 등) → 같은 이름의 .docx
2. 그래도 없으면 웹 검색으로 찾고, 출처 링크를 원고에 적습니다.
3. 끝내 못 찾으면 숫자를 지어내지 말고 멈춰서 사용자에게 숫자와 기관을 묻습니다.

말투는 「브랜드 규칙」을 따릅니다. 최고 · 완벽 · 놀라운 같은 말 대신 숫자와 사실을 씁니다. 장마다 쇼츠 자막으로 쓸 한 줄(20자 안팎)도 함께 정합니다.

다섯 장의 글을 표로 먼저 보여 주고, 바꾸고 싶은 곳이 있는지 한 번 묻습니다. 답이 없으면 그대로 진행합니다.

## 배경 그림 (선택, 사용자가 원할 때만)
기본은 단색 바탕입니다. 사용자가 「배경 그림 넣어 줘」라고 할 때만 `$imagegen` 으로 표지 배경 1장을 만듭니다. 규칙은 references/background.md 를 읽고 따릅니다. 이미지는 계정마다 하루에 만들 수 있는 수가 정해져 있으니 1장만 만들고, 다시 만들기는 사용자가 원할 때만 합니다.

## 만들기
1. 오늘 날짜로 `작업파일/카드뉴스_YYYYMMDD/cards.json` 을 씁니다. 형식은 `.agents/skills/cardnews/assets/cards_example.json` 과 똑같이 합니다 (color · brand · background_image · cards 5개 · subtitles 5개). brand 에는 사이트재료.md 「한 줄 소개」를 넣습니다.
2. 아래 명령으로 PNG 5장을 찍습니다. `python` 이 안 되면 `python3` 으로 바꿉니다.
   `python .agents/skills/cardnews/assets/make_cards.py 작업파일/카드뉴스_YYYYMMDD/cards.json 카드뉴스_YYYYMMDD`
3. 틀(card_template.html)이나 프로그램(make_cards.py)은 고치지 않습니다. HTML 을 새로 짜지 않습니다.
4. 「브라우저가 켜지다가 멈췄습니다」가 나오면 보안 상자(샌드박스) 때문입니다. 사용자에게 "카드 사진을 찍으려면 브라우저를 켜야 합니다. 허락해 주세요"라고 묻고, 허락을 받아 같은 명령을 샌드박스 밖에서 다시 실행합니다. 다른 방법(미리보기 앱 등)으로 우회하지 않습니다.
5. 「Chrome 이나 Edge 를 찾지 못했습니다」가 나오면 사용자에게 알리고, 허락을 받은 뒤에만 `python -m pip install playwright` 와 `python -m playwright install chromium` 을 실행하고 다시 찍습니다.

## 확인
PNG 5장을 하나씩 열어 봅니다. 글자가 잘리거나, 네모로 깨지거나, 칸을 넘친 장이 있으면 그 장의 글을 줄여 cards.json 을 고치고 2번 명령을 다시 실행합니다.

## 저장
- 이 폴더의 `카드뉴스_YYYYMMDD/` : `01_표지.png` ~ `05_행동.png` 와 `캡션.txt`
- `캡션.txt` 구성: 첫 줄 표지 문장 → 본문 2~3줄 → 추적 링크 → 해시태그 5개
- 추적 링크는 AGENTS.md [6] 꼬리표 규칙표의 인스타 줄을 따릅니다: 사이트 주소 뒤에 `?utm_source=instagram&utm_medium=social&utm_campaign=날짜_cardnews` (날짜는 오늘 월일 네 자리, 예: 1013_cardnews). 「작업파일/꼬리표링크.md」에 인스타 링크가 이미 있으면 그것을 그대로 씁니다. 주소에 이미 `?` 가 있으면 `?` 대신 `&` 로 잇습니다.
- `작업파일/카드뉴스_YYYYMMDD/` : cards.json · html 폴더 · `원고.md` (다섯 장 글, 숫자 출처 링크, 고른 색 코드)

끝나면 한 줄로 말합니다. 예: "카드 5장과 캡션.txt 를 카드뉴스_20261013 폴더에 저장했습니다. 근거 숫자는 ○○ (기관, 연도)입니다."
